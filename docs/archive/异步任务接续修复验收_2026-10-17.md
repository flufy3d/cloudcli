## 结论与适用范围

Codex 首版范围修复验收通过：原聊天结束回合、浏览器离线后，后台任务完成可自动续开原线程；结果与回执持久保存，竞争时不抢断用户，不确定发送不盲重投。结论限定于本页列明的自动化、隔离真实 Codex 和安装产物验证，不代表生产已上线。

实际接法是原聊天本轮 stdio MCP → 已认证宿主登记 → 独立 Codex `command/exec` worker → 原子结果文件 → 持久发件箱 → 原线程 `thread/resume` 与 `turn/start.toolOutput`。模型不需要一直保持原回合，浏览器也不需要在线。发送结果不明时进入 `needs_review`，不自动重投；因此这里保证持久保存、去重和保守处置，不宣称跨数据库与引擎实现无条件恰好一次。

总开关默认关闭。源码与安装产物已验证；生产实例仍运行原版本。本次没有 commit、合并、发布、部署或操作生产 PM2。

末期复核还修复了旧表新列索引的迁移顺序、重启后的同聊天顺序、旧登记 HTTP 入口绕过总开关、人工重试丢旧回执、可信接受回调被网关注入覆盖、用户停止正常返回误报 unknown。每项都有对应负例，未以全量测试数量代替这些边界。

## 崩溃与恢复矩阵

`task-continuation-worker-crash.test.ts` 的 checkpoint 测试启动子进程、持久保存指定状态后以非零码退出，再重开数据库调用生产恢复逻辑。不能把这类预置状态叫作真实 Codex 在所有时刻断电。另两项 dispatcher checkpoint 确实在生产派发回调中退出，历史持久化由假引擎提供。

| 故障点 | 验证层次 | 结果 |
| --- | --- | --- |
| 结果已落盘、未回调 | 真 worker/真宿主 SIGKILL；另有 checkpoint | 重启扫描一条事件，原线程汇报一次 |
| 新宿主上线后才有结果 | 真 worker/真 Codex、不同宿主 PID | 在线扫描补录，非仅启动扫描 |
| 事务已提交、尚未唤醒 | `committed-before-wakeup` 子进程状态夹具 | 轮询可领取 |
| 已领取、未写发送意图 | `claimed-before-send` 子进程状态夹具 | 过期租约回收后可发 |
| 已写发送意图、未调引擎 | `sending-before-engine-call` 状态夹具 | 证据不足 needs_review，不盲重发 |
| 引擎接受、未保存接受回执 | `engine-accepted-before-receipt` 生产派发器+持久假引擎历史 | 找到唯一原回合并补回执，不再领取 |
| 已接受、回答未完成 | `accepted-before-reply` 夹具与在线核对用例 | 继续核对原回合，不重投；正在本机执行时不抢写 |
| 回答完成、未存交付回执 | `reply-completed-before-delivery-receipt` 生产派发器+持久假引擎历史 | 由原回合终态补 delivered，一条假引擎 turn |
| 历史失败、不完整 | `history-unavailable` 夹具、官方分页客户端测试 | needs_review，原因可查 |
| 半写结果、worker 被杀 | `partial-result`；捕获本次 spawn 精确 PID 后 SIGKILL worker | 保留未确认/明确错误，不伪造成功、不自动重执行命令 |

## 独立复核与限制

规范复核 `final_standards`、设计符合性复核 `final_spec`、产品复核 `final_product` 均按实际 diff 和边界用例独立执行，末轮无剩余阻断。设计复核自行验证旧表升级、FIFO/未决屏障与重试旧回执保存；产品复核实际访问鉴权 HTTP/CLI 并验证取消、关闭、needs_review 及已接受审批提示。最后的 VAPID 惰性连接和三入口隔离由规范 Agent 独立复跑4/4；四事务多进程竞争由设计 Agent 独立强断言复核，均无阻断。

没有操作生产 PM2，没有部署生产包，没有在生产原聊天内试运行。生产是否接通必须等用户部署后另验。没有验证所有 Codex 版本、所有平台、全部第三方引擎真实账号或完整产品审批弹窗。总开关和 CLI 操作说明以[现行设计](../design/异步任务接续.md)为准；开发 API 是3001，管理开发实例必须显式设置 `CLOUDCLI_API_URL`，不要误用默认3030。

测试过程曾发生并纠正的装配问题：一个早期 fixture 未设置临时任务根，生成单个测试任务目录，已精确清理并改为隔离目录；数据库 fixture 预建空文件，阻止自动复制仓库 legacy DB；旧全局 ps 猜 worker PGID 的探针已换成本次 spawn 精确 PID；Chrome 清理先报 ENOTEMPTY，修复等待退出后完整失败场景已重跑 exit0。这些过程没有作为产品成功证据，也没有操作生产服务。
