# 图片预览

基准：2026-10-13

文件树图片、聊天图片附件、输入框图片附件和聊天 Markdown 中可展开的本地/工作区图片共用全屏图片查看器。工具栏提供缩小、放大、还原、下载图片和关闭操作。聊天 Markdown 中直接显示的 HTTP、data 和站内图片不提供全屏展开入口。

下载保存当前图片源的原始内容，缩放和拖动不影响保存结果。保存文件名优先使用文件路径的末段，其次使用标题、替代文字、HTTP 图片地址的文件名；没有名称时使用 `image`。完整 HTTP 地址作为标题时取图片地址的文件名，不含查询参数。文件名中的非法字符替换为下划线，没有扩展名时根据图片的媒体类型补全。

保存通过公共文件保存工具交给浏览器或系统文件分享菜单，支持文件分享的设备可选择保存到文件。处理中下载按钮不可重复触发；失败提示保留在查看器内，用户可以重试。外链图片受来源网站的跨域访问规则限制，能显示不代表能下载。

查看器操作文案：`下载图片`、`正在下载图片`；失败提示：`图片下载失败，请重试；外链图片可能不允许下载。`

代码编辑器的媒体预览属于独立界面，不使用这个全屏查看器。
