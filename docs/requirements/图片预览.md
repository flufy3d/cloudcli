# 图片预览

基准：2026-10-18

文件树图片、聊天图片附件、输入框图片附件、聊天 Markdown 中的本地/工作区图片，以及文档预览（文件查看器、PRD 编辑器）中解析成功的工作区图片，共用全屏图片查看器。工具栏提供缩小、放大、还原、下载图片和关闭操作。直接由浏览器加载的 HTTP、data 和 blob 图片不提供全屏展开入口。

下载保存当前图片源的原始内容，缩放和拖动不影响保存结果。保存文件名优先使用文件路径的末段，其次使用标题、替代文字、HTTP 图片地址的文件名；没有名称时使用 `image`。完整 HTTP 地址作为标题时取图片地址的文件名，不含查询参数。文件名中的非法字符替换为下划线，没有扩展名时根据图片的媒体类型补全。

保存通过公共文件保存工具交给浏览器或系统文件分享菜单，支持文件分享的设备可选择保存到文件。处理中下载按钮不可重复触发；失败提示保留在查看器内，用户可以重试。外链图片受来源网站的跨域访问规则限制，能显示不代表能下载。

查看器操作文案：`下载图片`、`正在下载图片`；失败提示：`图片下载失败，请重试；外链图片可能不允许下载。`

代码编辑器的媒体预览属于独立界面，不使用这个全屏查看器。

文档预览按文档所在目录解析图片引用：文件查看器预览用被打开文档的目录，PRD 编辑器预览用项目下的 `.taskmaster/docs` 目录。相对路径和 `../` 先按该目录归一化，再交给项目文件接口读取；`file://` 与以 `/` 开头的写法按绝对路径处理；项目外的只读文档（例如 Antigravity 计划文档）里的图片走外部只读文件接口。HTTP、data、blob 地址直接交给浏览器加载，仍受来源网站跨域规则限制。路径解析不出来、文件不存在或超出可读范围时，图片位置显示替代文字，不显示破图。

工具输出中的内嵌图片以资源文件保存，聊天记录提供默认折叠的「结果附件」入口，展开后才能加载预览。图片可用现有查看器放大和下载。大文本结果显示预览，并在结果附件中提供「完整输出.txt」下载原文。模型读取的原始工具结果不受展示处理影响，旧会话重新读取时同样适用。

结果附件文案：`结果附件（{{count}}）`、`完整输出.txt`，分别登记在 chat 词典的 `misc.outputAssets` 与 `misc.fullOutput`。

用户提示词不变为结果预览，复制和编辑重发使用完整原文。HTML、PDF 导出内嵌结果图片与全文资源，离线附件可展开和下载。JSON 导出携带资源映射。导出资源读取失败时提示导出失败，用户可修复后重试；完整导出的文件体积包含所有内嵌资源。
